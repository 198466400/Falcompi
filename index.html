FALCOM

Play your old floppy-disk games on a Raspberry Pi.

BEFORE YOU START

  • A Raspberry Pi running Raspberry Pi OS, connected to the internet
  • A USB floppy drive (the Pi has no floppy port of its own)
  • Your floppy disks. PC/DOS disks work. Disks from Amiga, Apple II or Commodore machines use formats Linux can’t read this way.

  1. Open Terminal

    Click the black Terminal icon (>_) in the top bar of your Pi’s screen.

  2. Install git

    Copy this, paste it into Terminal, and press Enter.

    sudo apt update && sudo apt install -y git

    The installer in step 4 adds RetroArch and DOSBox for you.

  3. Download Falcom

    git clone https://github.com/{{REPO}}.git ~/Falcom

    If it says the folder already exists, Falcom is already downloaded. Go on to step 4.

  4. Run the installer

    cd ~/Falcom && chmod +x Falcom.sh && ./Falcom.sh

    This takes a few minutes. It may ask for your password. Nothing shows while you type it, and that’s normal.

    When you see “Falcom installed.” you’re done.

  5. Load a floppy and start

    Plug in the USB floppy drive and put a disk in. Then double-click the Falcom icon on the desktop, or run:

    ~/Falcom/bin/falcom

    Falcom copies the disk’s files into ~/Falcom/Games and opens RetroArch.

    No desktop icon, or it won’t open? Check your username with whoami. The icon only works if the answer is pi. Otherwise use the command above.

  6. Play DOS games

    See what was copied:

    ls ~/Falcom/Games

    Then start a game. Replace GAME.EXE with a file name from that list, typed exactly:

    dosbox ~/Falcom/Games/GAME.EXE

  7. Remove the disk safely

    Before you pull the disk out of the drive, run:

    sudo umount /mnt

IF SOMETHING GOES WRONG

Nothing was copied from my disk

Check how the Pi sees the drive:

lsblk

A floppy shows up as a tiny disk of about 1.4M, usually sda. Falcom reads /dev/sda only. If yours is sdb or another name, run nano ~/Falcom/bin/falcom and change sda to match.

Also try another disk. Old floppies often fail, and some USB drives need a powered port.

Games inside folders on the disk are missing

Falcom copies only the files at the top level of the disk, not folders inside it. Most floppy games keep everything at the top level, so this rarely matters.

RetroArch opens but there’s nothing to play

RetroArch needs a “core” for each kind of game and none are installed by default. For DOS games, skip it and use step 6 (DOSBox) instead.

A command shows an error

Take a screenshot of the Terminal showing the full error and send it to whoever gave you this page.
