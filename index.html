Falcom – Raspberry Pi Floppy Game Setup

This page will walk you through installing Falcom on your Raspberry Pi so you can play games from your old floppy disks.

Step 1 – Open Terminal on your Raspberry Pi

On your Raspberry Pi, click the Terminal icon on the top bar or in the menu.

Step 2 – Install required software

Copy and paste this command into the Terminal, then press Enter:

sudo apt update && sudo apt install -y retroarch dosbox git

Step 3 – Download Falcom from GitHub

Copy and paste this command into the Terminal:

git clone https://github.com/YOUR-USER/Falcompi.git ~/Falcom

Replace YOUR-USER with the GitHub username that hosts Falcom.

Step 4 – Make Falcom ready to run

Run these commands in Terminal, one at a time:

cd ~/Falcom
chmod +x Falcom.sh

This makes the Falcom script executable.

Step 5 – Run Falcom

Now you can start Falcom with:

cd ~/Falcom && ./Falcom.sh

Follow any prompts Falcom shows to scan your floppy and load games.

Optional – Create a desktop icon

If you want a clickable icon on the desktop, run:

echo "[Desktop Entry]
Type=Application
Name=Falcom
Exec=/home/pi/Falcom/Falcom.sh
Icon=system-run
Terminal=true" > ~/Desktop/Falcom.desktop
chmod +x ~/Desktop/Falcom.desktop

After this, you can double-click Falcom on the desktop.
